# اعرف منتجك | Know Your Product

تطبيق عربي RTL للبحث عن معلومات المنتجات عبر الاسم أو الباركود أو نص مستخرج من صورة، مع قراءة الباركود بالكاميرا وبطاقة توضح البيانات المتاحة ومصدرها.

## الوظائف
- البحث بالاسم أو رقم الباركود في ثلاث قواعد بيانات مفتوحة: Open Food Facts للأغذية، Open Beauty Facts لمستحضرات التجميل، وOpen Products Facts لمنتجات أخرى.
- مسح الباركود بالكاميرا عبر html5-qrcode (يتطلب إذن الكاميرا واتصالًا لتحميل المكتبة).
- استخراج النص من صورة المنتج عبر Tesseract.js باللغتين العربية والإنجليزية للمساعدة في البحث بالاسم؛ راجع النص المستخرج يدويًا.
- تفاصيل المنتج: العلامة التجارية، المكونات المتاحة، التحذيرات المسجلة، بيانات البلد/الكمية، ورابط المصدر.
- واجهة عربية متجاوبة، دعم RTL، وسياسة خصوصية.
- تخزين مؤقت لهيكل الواجهة لفتحها مجددًا دون اتصال؛ البحث عن بيانات جديدة يحتاج إنترنت.
- خادم Express اختياري لاستضافة الويب وواجهة API محلية ومساهمات المستخدمين.
- سير عمل GitHub Actions لبناء APK تجريبي قابل للتثبيت.

## تشغيل نسخة الويب
يتطلب Node.js 20 أو أحدث:
```bash
npm install
npm run check
npm start
```
ثم افتح http://localhost:3000.

## بناء APK عبر GitHub
1. ادفع الملفات إلى الفرع `main`.
2. افتح تبويب **Actions** واختر **Build Android APK**.
3. انتظر نجاح جميع الخطوات، ثم افتح تشغيل البناء وحمّل artifact باسم `know-your-product-debug-apk`.
4. فك الضغط عن artifact وثبّت `app-debug.apk` على جهاز Android. قد تحتاج السماح بالتثبيت من هذا المصدر.

ملف APK الناتج هو **Debug APK** للاختبار وليس نسخة Release موقعة للنشر في Google Play. لا تعتبره جاهزًا قبل نجاح GitHub Actions وتنزيل الملف فعليًا.

## حدود الدقة والخصوصية
توسيع المصادر يزيد فرص العثور على المنتج لكنه لا يضمن العثور على كل شيء: هذه قواعد بيانات مجتمعية مفتوحة وقد تكون ناقصة أو غير محدثة، وقد لا تحتوي المنتجات المحلية أو الأجهزة أو الأدوية أو الأشياء غير المسجلة. لا يعرض التطبيق معلومات غير موجودة على أنها حقائق مؤكدة، ويجب مراجعة المصدر والملصق الأصلي. للحصول على بحث ويب عام أوسع أو تحديد أي شيء من صورة، يلزم دمج خدمة بحث/رؤية مناسبة ومهيأة بمفاتيحها وشروطها. لا يعني غياب التحذيرات أن المنتج آمن. الاستدلال على الاستخدام من الاسم ليس توصية طبية. عند البحث، تُرسل كلمة البحث أو الباركود إلى Open Beauty Facts أو Open Food Facts. قراءة الباركود بالكاميرا تتم على الجهاز. وقد تستخدم الواجهة التخزين المؤقت لملفاتها الأساسية؛ لا تُخزّن نتائج البحث الحساسة محليًا.

## الخادم والبيانات
تخزن المساهمات في `data/contributions.json` كحل أولي. هذا ليس مخزنًا إنتاجيًا ولا يضمن الاستمرارية على منصات الاستضافة المؤقتة. قبل الإطلاق العام أضف مراجعة إدارية آمنة وقاعدة بيانات دائمة، واختبر الحماية والنسخ الاحتياطي.


## الإصدار 1.5.0: التخزين الدائم واستيراد البيانات

يدعم الخادم الآن PostgreSQL اختياريًا. عند ضبط `DATABASE_URL` ينشئ الجداول المطلوبة من `database/schema.sql` ويستخدم قاعدة البيانات لعمليات البحث بالباركود والاسم ولحفظ مساهمات المستخدمين. عند عدم ضبطه، يعمل وضع JSON السابق كخيار تطوير محلي محدود.

### تشغيل الخادم مع PostgreSQL عبر Docker

1. ثبّت Docker وDocker Compose على جهاز الخادم.
2. انسخ `.env.example` إلى `.env`، واختر كلمة مرور طويلة وعشوائية لقيمة `POSTGRES_PASSWORD`.
3. شغّل `docker compose up --build -d`.
4. اختبر `http://localhost:3000/api/health`. يجب أن تظهر `database: "postgresql"` بعد نجاح الاتصال.

لا تنشر كلمة مرور قاعدة البيانات في GitHub، ولا تستخدم كلمة المرور الافتراضية في الإنتاج. يحتاج النشر العام إلى HTTPS، ونسخ احتياطية، ومراقبة، وإدارة آمنة للمساهمات قبل اعتمادها.

### استيراد قاعدة منتجات كبيرة

نزّل ملف بيانات JSONL من مصدر بيانات يسمح لك باستخدامه، ثم شغّل من بيئة لديها Node.js و`DATABASE_URL` وصول إلى PostgreSQL:

```bash
npm install
npm run import:products -- /path/to/products.jsonl
```

يقبل المستورد سجل JSON واحدًا في كل سطر، ويحتاج كل سجل إلى `code` أو `barcode` واسم منتج مثل `product_name`. يكتب الدفعات في PostgreSQL ويحدّث السجل عند تكرار الباركود. المستورد لا ينزّل قاعدة البيانات بنفسه ولا يضمّن ملفًا ضخمًا في المستودع؛ عليك تنزيل ملف المصدر ومراجعة شروط ترخيصه وتاريخ تحديثه وحجمه قبل الاستيراد. بيانات المصادر المجتمعية قد تكون ناقصة أو غير دقيقة، ويجب إظهار مصدرها واحترام شروط الإسناد والترخيص.

### المحفوظات

يمكن حفظ المنتجات من بطاقة التفاصيل محليًا على الجهاز. لا تتم مزامنتها بين الأجهزة، ومسح بيانات المتصفح أو التطبيق قد يحذفها.

### حدود ما تم تجهيزه

وجود مخطط PostgreSQL وDocker والمستورد يجهّز المشروع للتشغيل، لكنه لا يعني أن قاعدة خارجية تم إنشاؤها أو أن ملفًا ضخمًا تم تنزيله واستيراده أو أن الخادم تم نشره على الإنترنت. كما أن تطبيق Android الحالي يبحث مباشرة في المصادر المفتوحة؛ ربطه بخادم مستضاف يتطلب عنوان HTTPS فعليًا وتكوينًا واختبارات اتصال قبل استخدامه في نسخة الإنتاج.
