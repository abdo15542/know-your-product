# اعرف منتجك | Know Your Product

تطبيق عربي RTL للبحث عن معلومات المنتجات عبر الاسم أو الباركود أو نص مستخرج من صورة، مع قراءة الباركود بالكاميرا وبطاقة توضح البيانات المتاحة ومصدرها.

## الوظائف
- البحث بالاسم أو رقم الباركود في Open Beauty Facts وOpen Food Facts.
- مسح الباركود بالكاميرا عبر html5-qrcode (يتطلب إذن الكاميرا واتصالًا لتحميل المكتبة).
- استخراج النص من صورة المنتج عبر Tesseract.js باللغتين العربية والإنجليزية للمساعدة في البحث بالاسم؛ راجع النص المستخرج يدويًا.
- تفاصيل المنتج: العلامة التجارية، المكونات المتاحة، التحذيرات المسجلة، بيانات البلد/الكمية، ورابط المصدر.
- واجهة عربية متجاوبة، دعم RTL، وسياسة خصوصية.
- تخزين مؤقت لهيكل الواجهة لفتحها مجددًا دون اتصال؛ البحث عن بيانات جديدة يحتاج إنترنت.
- خادم Express اختياري لاستضافة الويب وواجهة API محلية ومساهمات المستخدمين.
- سير عمل GitHub Actions لبناء APK تجريبي قابل للتثبيت.

## تشغيل نسخة الويب
يتطلب Node.js 20 أو أحدث:
```bash
npm install
npm run check
npm start
```
ثم افتح http://localhost:3000.

## بناء APK عبر GitHub
1. ادفع الملفات إلى الفرع `main`.
2. افتح تبويب **Actions** واختر **Build Android APK**.
3. انتظر نجاح جميع الخطوات، ثم افتح تشغيل البناء وحمّل artifact باسم `know-your-product-debug-apk`.
4. فك الضغط عن artifact وثبّت `app-debug.apk` على جهاز Android. قد تحتاج السماح بالتثبيت من هذا المصدر.

ملف APK الناتج هو **Debug APK** للاختبار وليس نسخة Release موقعة للنشر في Google Play. لا تعتبره جاهزًا قبل نجاح GitHub Actions وتنزيل الملف فعليًا.

## حدود الدقة والخصوصية
مصادر المنتجات المفتوحة قد تكون ناقصة أو غير محدثة، وقد لا تحتوي المنتجات المحلية. لا يعني غياب التحذيرات أن المنتج آمن. الاستدلال على الاستخدام من الاسم ليس توصية طبية. عند البحث، تُرسل كلمة البحث أو الباركود إلى Open Beauty Facts أو Open Food Facts. قراءة الباركود بالكاميرا تتم على الجهاز. وقد تستخدم الواجهة التخزين المؤقت لملفاتها الأساسية؛ لا تُخزّن نتائج البحث الحساسة محليًا.

## الخادم والبيانات
تخزن المساهمات في `data/contributions.json` كحل أولي. هذا ليس مخزنًا إنتاجيًا ولا يضمن الاستمرارية على منصات الاستضافة المؤقتة. قبل الإطلاق العام أضف مراجعة إدارية آمنة وقاعدة بيانات دائمة، واختبر الحماية والنسخ الاحتياطي.
